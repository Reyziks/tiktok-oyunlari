# TikTok Oyunları

Bu depo yalnızca **TikTok Oyunları** uygulamasının kurulum dosyalarını ve oyun paketlerini barındırır.

- **Kurulum:** [Releases](https://github.com/Reyziks/tiktok-oyunlari/releases/latest) sayfasından `TiktokOyunlari-Setup-*.exe` dosyasını indirip çalıştırın. Sonraki sürümler uygulama içinden otomatik gelir.
- **Oyunlar:** `oyunlar.json` kataloğu ve `oyunlar/` klasörü; uygulamadaki *Oyunlar → Mağaza* bölümü buradan okur.

Windows "bilinmeyen yayımcı" uyarısı verirse: **Ek bilgi → Yine de çalıştır**.
